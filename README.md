# Pracownia Programowania

To repozytorium zostało stworzone z myślą o uczniach **Zespołu Szkół Łączności w Gdańsku**.

## Opis

Repozytorium zawiera materiały dydaktyczne do nauki programowania. Jego celem jest pomoc w zrozumieniu kluczowych koncepcji programistycznych poprzez teorię i praktyczne ćwiczenia.

## Struktura Repozytorium

- `Teoria.ipynb`: Notatnik Jupyter zawierający materiały teoretyczne, objaśnienia i przykłady kodu.
- `Zadania.ipynb`: Notatnik Jupyter z zadaniami do samodzielnego rozwiązania, które pomogą utrwalić zdobytą wiedzę.
